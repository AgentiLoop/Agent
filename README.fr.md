# 🦾 Agent! pour macOS 26.4.1 ou version ultérieure

## IA agentique pour votre bureau Apple Mac

Agent! est une application native pour macOS qui transforme votre Mac en un agent intelligent capable de comprendre des instructions en langage naturel, d’exécuter des tâches, d’automatiser des applications, de modifier des fichiers, de compiler des projets, de gérer Git et d’interagir avec le bureau de manière sécurisée.

## Qu’est-ce qu’Agent! ?

Agent! ne se contente pas de répondre à des questions : il exécute des actions. Il peut ouvrir des applications, rechercher sur le web, naviguer dans Safari, lire et modifier des fichiers, construire des projets Xcode, exécuter des scripts et automatiser des tâches système.

Il fonctionne avec des modèles IA locaux ou cloud. Vous pouvez utiliser votre propre clé API ou des solutions locales comme Ollama, vLLM ou LM Studio.

## Démarrage rapide

1. Téléchargez Agent! depuis la dernière version du dépôt.
2. Faites-le glisser vers le dossier Applications.
3. Ouvrez l’application et laissez-la se configurer.
4. Dans Réglages, choisissez votre fournisseur d’IA et ajoutez votre clé API ou sélectionnez un fournisseur local.

## Fonctionnalités clés

### IA agentique
Agent! combine raisonnement, exécution et correction automatique. Il ne se contente pas de générer du texte : il observe les résultats, corrige les erreurs et recommence jusqu’à ce que la tâche soit terminée.

### Codage agentique
Il peut lire un codebase, modifier des fichiers précisément, exécuter des commandes shell, compiler un projet Xcode, gérer Git et travailler dans un mode de développement orienté agent.

### Automatisation du bureau
Agent! contrôle les applications macOS via Accessibility, AppleScript, JXA, ScriptingBridge et Safari Automation.

### Support multi-modèles
Agent! peut se connecter à plusieurs fournisseurs d’IA, dont Claude, OpenAI, Gemini, Grok, Mistral, DeepSeek, Qwen, Z.ai, BigModel, Hugging Face, OpenRouter, Ollama, vLLM, LM Studio et Apple Intelligence.

### Confidentialité et sécurité
Vos données restent sur votre Mac. Les tâches d’IA et les actions automatisées sont enregistrées et visibles dans le journal d’activité.

## Confidentialité et sécurité

- Vos fichiers et données restent sur votre ordinateur.
- Seuls les textes de vos prompts sont envoyés aux fournisseurs cloud.
- Vous pouvez vérifier exactement ce que l’agent a fait dans le journal.
- Le système applique les autorisations et les garde-fous nécessaires avant d’exécuter des tâches sensibles.

## FAQ

### Dois-je savoir coder ?
Non. Il suffit de décrire ce que vous souhaitez en anglais ou dans votre langue naturelle.

### C’est sûr ?
Oui. Agent! affiche un journal complet, exige les autorisations macOS nécessaires et limite les actions sensibles.

### Combien ça coûte ?
L’application est gratuite et open source. Les fournisseurs cloud facturent selon leur usage, mais les modèles locaux sont également possibles.

### Quel Mac faut-il ?
macOS 26.4.1 ou version ultérieure, avec processeur Apple Silicon. Les modèles locaux exigent davantage de mémoire et de puissance selon leur taille.
