# Sponsoring 🦾 Agent!

Agent! is a free, MIT-licensed, 100% native Swift macOS agent maintained by [AgentiLoop.ai](https://agentiloop.ai) (Logos InkPen LLC, North Carolina, USA). Sponsorship keeps the project independent and funds the things that don't fund themselves: CI minutes on macOS runners, Apple Developer / notarization, provider API testing across 21 backends, and maintainer time.

> **LLM API providers, gateways, and model hosts:** see the [Provider Partner Program](./PROVIDER_PROGRAM.md) — it replaces the general tiers below with provider-specific pricing (Listed / Sponsor / Partner) and a compatibility standard.

All sponsorships run through **[GitHub Sponsors → AgentiLoop](https://github.com/sponsors/AgentiLoop)** (recurring or one-time). Invoiced billing is available for company sponsors at Silver and above. **Cash only** — API credits, discounts, hardware, and other in-kind offers are not accepted in place of a tier fee.

## Tiers

Every tier is monthly unless marked one-time. Sponsor badges require a minimum 3-month term; annual prepay = 12 months for the price of 10. **No logos, no banners, no slots** — every sponsor is listed the same way, with a sponsor badge.

| Tier | Price | What you get |
|---|---|---|
| **Supporter** | $5 / mo | Name listed in `SPONSORS.md`; sponsor badge on GitHub |
| **Backer** | $25 / mo | Name + link in the README **Sponsors** section |
| **Bronze** | $100 / mo | Name + link in the README **Sponsors** section and on agentiloop.ai; mention in release notes |
| **Silver** | $500 / mo | Everything in Bronze, plus — for LLM/API providers Agent! can talk to — a **sponsor badge** on your row in the README **LLM Providers** table and on the agentiloop.ai **LLM Providers** page; a maintainer-written configuration guide in `docs/providers/`; announcement in GitHub Discussions |
| **Gold** | $1,500 / mo | Everything in Silver, plus: first-class provider preset in the in-app picker; "Sponsored" callout in the FAQ cost section; co-marketing (blog post / social announcement on agentiloop.ai); quarterly 30-minute roadmap call |
| **Platinum** | $5,000 / mo | Everything in Gold, plus: priority handling of compatibility issues with your endpoint; early access to pre-release builds; input on provider-related roadmap items |

## Perks for Agent! users

Discounts or perks offered **to Agent! users** (promo codes, free credit on signup) are listed in the FAQ and the provider guide regardless of tier — they help our users, so we're happy to publish them. They are not a substitute for a tier fee.

## Placement formats and durations

| Placement | Where | Availability |
|---|---|---|
| Sponsors section | `README.md` → **Sponsors** | Backer+ |
| Website sponsors list | agentiloop.ai | Bronze+ |
| LLM Providers row + sponsor badge | `README.md` → **LLM Providers** and agentiloop.ai → **LLM Providers** | Provider sponsors, Silver+ |
| Configuration guide | `docs/providers/<name>.md`, linked from README + FAQ | Silver+ |
| Release notes mention | `docs/PRE_RELEASE_*.md` + GitHub Release body | Bronze+ / Release sponsor |
| Discussions announcement | GitHub Discussions → Announcements | Silver+ |

Minimum term for sponsor badges: 3 months. Cancel any time after that; the badge is removed at the end of the paid month. No slot limits — every sponsor is listed.

## What sponsorship does **not** buy

- Changes to Agent!'s default provider, default model, or telemetry (there is none).
- Removal or down-ranking of competing providers.
- Any data about Agent! users — the app has no analytics.
- Editorial control over benchmarks, comparisons, or the FAQ's cost recommendations. We'll list your offer accurately; we won't say it's the best unless we've measured it.
