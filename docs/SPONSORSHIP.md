# Sponsoring 🦾 Agent!

Agent! is a free, MIT-licensed, 100% native Swift macOS agent maintained by [AgentiLoop.ai](https://agentiloop.ai) (Logos InkPen LLC, North Carolina, USA). Sponsorship keeps the project independent and funds the things that don't fund themselves: CI minutes on macOS runners, Apple Developer / notarization, provider API testing across 21 backends, and maintainer time.

> **LLM API providers, gateways, and model hosts:** see the [Provider Sponsorship & Integration](./PROVIDER_PROGRAM.md) — name + sponsorship badge in the README under LLM Providers at any tier, logo on the website at Gold/Platinum, and a flat $1,500 integration fee.

All sponsorships run through **[GitHub Sponsors → AgentiLoop](https://github.com/sponsors/AgentiLoop)** (recurring or one-time). Invoiced billing is available for company sponsors at Silver and above. **Cash only** — API credits, discounts, hardware, and other in-kind offers are not accepted in place of a tier fee.

## Tiers

Monthly prices. Sponsor badges require a 3-month minimum; annual prepay = 12 months for the price of 10.

| Tier | Price | What you get |
|---|---|---|
| **Supporter** | $5 / mo | Name listed in `SPONSORS.md`; sponsor badge on GitHub |
| **Backer** | $25 / mo | Name + link in the README **Sponsors** section |
| **Bronze** | $100 / mo | Name + link in the README **Sponsors** section and on agentiloop.ai; mention in release notes |
| **Silver** | $500 / mo | Everything in Bronze. **LLM Providers:** name + Silver badge in the README **LLM Providers** table, Silver badge on the website LLM Providers page, entry in Agent!'s in-app Sponsors menu |
| **Gold** | $1,500 / mo | Everything in Silver. **LLM Providers:** website LLM Providers **card with your logo**, linking to your website |
| **Platinum** | $2,500 / mo | Everything in Gold, plus: priority handling of compatibility issues with your endpoint; early access to pre-release builds; input on provider-related roadmap items |

## What sponsorship does **not** buy

- Changes to Agent!'s default provider, default model, or telemetry (there is none).
- Removal or down-ranking of competing providers.
- Any data about Agent! users — the app has no analytics.
- Editorial control over benchmarks, comparisons, or the FAQ's cost recommendations. We'll list your offer accurately; we won't say it's the best unless we've measured it.
