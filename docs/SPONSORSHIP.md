# Sponsoring 🦾 Agent!

Agent! is a free, MIT-licensed, 100% native Swift macOS agent maintained by [AgentiLoop.ai](https://agentiloop.ai) (Logos InkPen LLC, North Carolina, USA). Sponsorship keeps the project independent and funds the things that don't fund themselves: CI minutes on macOS runners, Apple Developer / notarization, provider API testing across 21 backends, and maintainer time.

All sponsorships run through **[GitHub Sponsors → AgentiLoop](https://github.com/sponsors/AgentiLoop)** (recurring or one-time). Invoiced billing is available for company sponsors at Silver and above.

## Tiers

Every tier is monthly unless marked one-time. Logo placements require a minimum 3-month term; annual prepay = 12 months for the price of 10.

| Tier | Price | What you get |
|---|---|---|
| **Supporter** | $5 / mo | Name listed in `SPONSORS.md`; sponsor badge on GitHub |
| **Backer** | $25 / mo | Name + link in the README **Sponsors** section |
| **Bronze** | $100 / mo | Small logo in the README Sponsors section; mention in release notes |
| **Silver** | $500 / mo | Medium logo in README Sponsors section; row in the README **AI Providers** table (if you are an LLM/API provider Agent! can talk to); a maintainer-written configuration guide in `docs/providers/`; announcement in GitHub Discussions |
| **Gold** | $1,500 / mo | Everything in Silver, plus: logo in the README header banner (max 3 Gold slots); "Recommended" callout in the provider table and FAQ cost section; co-marketing (blog post / social announcement on agentiloop.ai); quarterly 30-minute roadmap call |
| **Platinum** | $5,000 / mo | Everything in Gold, plus: exclusive top-of-README banner (1 slot); logo on agentiloop.ai; priority handling of compatibility issues with your endpoint; input on provider-related roadmap items |

## In-kind sponsorship (API credits, discounts, hardware)

We accept in-kind sponsorship and credit it at **50% of face value** toward a tier. Example: $1,000/month of API credits used for CI and provider testing counts as $500/month → Silver.

Discounts or perks offered **to Agent! users** (promo codes, free credit on signup) are listed in the FAQ and the provider guide regardless of tier — they help our users, so we're happy to publish them.

## What sponsorship does **not** buy

- Changes to Agent!'s default provider, default model, or telemetry (there is none).
- Removal or down-ranking of competing providers.
- Any data about Agent! users — the app has no analytics.
- Editorial control over benchmarks, comparisons, or the FAQ's cost recommendations. We'll list your offer accurately; we won't say it's the best unless we've measured it.
