# 🦾 Agent! for macOS 26.4.1 以降

## あなたの Mac デスクトップ向け Agentic AI

Agent! はネイティブの macOS アプリで、Mac をインテリジェントなエージェントに変えます。自然言語の指示を理解し、タスクを実行し、アプリを自動化し、ファイルを編集し、プロジェクトをビルドし、Git を管理し、デスクトップを安全に操作できます。

## Agent! とは？

Agent! は単なるチャットボットではなく、実際の行動を実行します。アプリを開いたり、Web を検索したり、Safari を操作したり、ファイルを読み書きしたり、Xcode プロジェクトをビルドしたり、スクリプトを実行したり、システムタスクを自動化できます。

ローカルモデルとクラウドモデルの両方を使えます。独自の API キーを使うことも、Ollama、vLLM、LM Studio などのローカル環境を使うこともできます。

## クイックスタート

1. リポジトリの最新リリースから Agent! をダウンロードします。
2. アプリを Applications フォルダにドラッグします。
3. アプリを開いて初期設定を行います。
4. 設定から AI プロバイダーを選び、API キーを入力するか、ローカルモデルを選択します。

## 何ができる？

- 「Music で Workout プレイリストを再生して」
- 「Xcode プロジェクトをビルドしてエラーを修正して」
- 「Photo Booth で写真を撮って」
- 「母に 18 時に帰ると伝える iMessage を送って」
- 「Safari を開いて東京への航空券を検索して」
- 「このクラスを小さなファイルにリファクタリングして」
- 「今日のカレンダーイベントは何？」

やりたいことを書くだけで、Agent! がどう実行するかを判断します。

## 主な機能

### Agentic AI
Agent! は推論、実行、自動修正を組み合わせています。単に文章を生成するだけでなく、結果を確認し、エラーを修正し、タスクが完了するまで繰り返します。

### Agentic コーディング
コードベースを読み、ファイルを正確に編集し、シェルコマンドを実行し、Xcode プロジェクトをビルドし、Git を管理し、開発フローに集中できます。

### デスクトップ自動化
Agent! は Accessibility、AppleScript、JXA、ScriptingBridge、Safari Automation を使って macOS アプリを制御できます。

### マルチモデル対応
Agent! は Claude、OpenAI、Gemini、Grok、Mistral、DeepSeek、Qwen、Z.ai、BigModel、Hugging Face、OpenRouter、Ollama、vLLM、LM Studio、Apple Intelligence など複数の AI プロバイダーに接続できます。

### プライバシーとセキュリティ
データは Mac の中に残ります。AI タスクや自動化の実行内容はログに保存され、何が起きたかを確認できます。

## プライバシーとセキュリティ

- ファイルやデータはローカルに保持されます。
- プロンプト本文のみがクラウド AI に送信されます。
- 活動ログで Agent! が何をしたかを確認できます。
- 機密タスクの実行前に、必要な macOS 権限と安全対策が要求されます。

## よくある質問

### コーディングの知識が必要ですか？
いいえ。英語または母語でやりたいことを書くだけで十分です。

### 安全ですか？
はい。Agent! はアクティビティを記録し、必要な macOS 権限を要求し、危険な操作を制限します。

### どのくらいの費用ですか？
アプリ自体は無料でオープンソースです。クラウド AI は利用量に応じて課金されますが、ローカルモデルも利用できます。

### 必要な Mac は？
macOS 26.4.1 以降と Apple Silicon 搭載の Mac が必要です。ローカルモデルはモデルサイズに応じてメモリと性能が必要です。
